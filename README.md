# جدول تناوبی سه‌بعدی — کنترل با لمس و دست

بدون build؛ فقط فایل‌های استاتیک. three.js و MediaPipe از CDN بارگذاری می‌شوند (به اینترنت نیاز دارد).

## ساختار
```
index.html        صفحه و رابط کاربری
css/style.css     استایل واکنشگر (موبایل/تبلت/دسکتاپ، landscape، safe-area)
js/main.js        نقطهٔ ورود و اتصال دکمه‌ها
js/scene.js       صحنهٔ CSS3D: جدول/کره، نما (چرخش/زوم/جابه‌جایی)، انیمیشن، انتخاب
js/pointer.js     کنترل ماوس و لمس (چندلمسی، اینرسی)
js/hands.js       تشخیص دست و ژست‌ها (MediaPipe)
js/ui.js          پنل اطلاعات، توست، نشانگر، راهنما
js/data.js        دادهٔ ۱۱۸ عنصر
```

## اجرا روی کامپیوتر
```
python3 -m http.server 8000      # یا:  npm start
```
سپس `http://localhost:8000` را باز کنید. (دابل‌کلیک روی فایل به‌خاطر ES Module کار نمی‌کند.)

## اجرا روی گوشی
مرورگر **دوربین را فقط روی HTTPS (یا localhost)** اجازه می‌دهد؛ آدرس شبکهٔ محلی مثل `http://192.168.x.x`
روی گوشی لمس و نمایش را نشان می‌دهد ولی دوربین کار نمی‌کند. دو راه:

1. **انتشار رایگان با HTTPS** (توصیه‌شده): پوشه را روی GitHub Pages، Netlify (Drag & Drop) یا Vercel بگذارید.
2. **تونل موقت از کامپیوتر**: `npx localtunnel --port 8000` (یا cloudflared/ngrok) و باز کردن آدرس https روی گوشی.

## کنترل‌ها
| ورودی | کار |
|---|---|
| کشیدن (لمس/ماوس) | چرخش با اینرسی؛ وقتی جدول زوم شده: جابه‌جایی |
| دو انگشت | زوم + جابه‌جایی |
| تپ روی عنصر | اطلاعات؛ روی صفحهٔ کوچک، کارت ریز خودکار بزرگ می‌شود |
| 🖐️ کف دست باز | چرخش (در حالت زوم: جابه‌جایی) |
| ☝️ اشاره | نشانگر؛ حدود ۰٫۷۵ ثانیه ثابت بمانید = انتخاب |
| 👌 پینچ شست و اشاره | کلیک فوری |
| 🤏 شست و اشاره (اشاره باز، سه انگشت دیگر جمع) | بازتر = زوم به داخل؛ بسته‌تر = زوم به بیرون |
| ✊ مشت + نزدیک/دور | زوم |
| 🤲 دو دست | زوم |
| ✌️ / 👍 / 🤟 (نگه‌داشتن) | جدول↔کره / بازنشانی / چرخش خودکار |

## تنظیمات قابل‌تغییر
در `js/hands.js` بالای فایل: `DWELL_SELECT`، `DWELL_ACTION`، `PINCH_ON/OFF`.
حساسیت زوم شست و اشاره در تابع `_fingerZoom`، و حساسیت چرخش با دست در تابع `_rotate` (ضرایب `5` و `4`).
فیلتر: `new OneEuro(minCutoff, beta)` — minCutoff کمتر = نرم‌تر، beta بیشتر = تأخیر کمتر در حرکت سریع.

## تشخیص دست و عیب‌یابی
دوربین باید روی **HTTPS یا localhost** اجرا شود و مجوز Camera در مرورگر داده شده باشد.

ابتدا `@mediapipe/tasks-vision` و مدل رسمی Gesture Recognizer بارگذاری می‌شوند. اگر بارگذاری مدل شکست بخورد، استنتاج چند بار خطا بدهد یا مدل بعد از شروع برای چند ثانیه هیچ مختصاتی از دست برنگرداند، برنامه خودکار به موتور جایگزین `@mediapipe/hands` می‌رود. موتور جایگزین نقاط ۲۱گانهٔ دست را از CDN جاوااسکریپت می‌گیرد و ژست‌های پایه را از روی هندسهٔ انگشتان تشخیص می‌دهد؛ بنابراین دیگر برای آن مسیر لازم نیست فایل `.task` از Google Storage دانلود شود.

هر دو موتور برای دریافت فایل‌های کتابخانه/مدل به اینترنت و دسترسی به `cdn.jsdelivr.net` نیاز دارند. اگر پیام «مدل دست بارگذاری نشد» دیده شد، اتصال به این دامنه را بررسی کنید و سپس صفحه را دوباره بارگذاری کنید. اگر خود دوربین باز نشد، مجوز Camera سایت و تنظیمات حریم خصوصی دوربین در سیستم‌عامل را بررسی کنید و برنامه‌های دیگری را که ممکن است دوربین را اشغال کرده باشند ببندید.

## نمایش تمام‌صفحهٔ دوربین

با فعال‌کردن «کنترل دست»، تصویر زندهٔ دوربین تمام صفحه را می‌پوشاند و پشت جدول سه‌بعدی نمایش داده می‌شود. لایهٔ دوربین و خطوط تشخیص دست به کلیک‌ها و لمس‌های جدول دسترسی نمی‌گیرند؛ بنابراین چرخاندن جدول و انتخاب عناصر همچنان کار می‌کند. برای خاموش‌کردن تصویر پس‌زمینه و کنترل دست، دوباره دکمهٔ «توقف دست» را بزنید.
